# 常见问题

**Wilco 会取代 Pi 吗？**
不会。Pi 仍然像原来一样运行在你的 Mac 上，Wilco 只是它的遥控器。

**需要注册账号吗？**
不需要。手机扫一下二维码，就能直接和 Mac 配对。

**Mac 需要一直开着吗？**
需要。Pi 运行在你的 Mac 上，Mac 必须开机并联网，你才能连上它。会话运行期间，Wilco Host 可以阻止 Mac 进入睡眠。

**还能继续在终端里使用 Pi 吗？**
可以。安装 `wilco-bridge` 后，手机就能跟随并驱动你在终端中开启的会话。同一时间只有一方能写入同一个会话。

**支持哪些 Pi 版本？**
Mac Host 会检查已安装的 Pi 版本，并在每次 Pi 升级后自动运行兼容性检查。每个版本的发布说明中都会列出支持的 Pi 版本。

**为什么中继开源，iOS App 却不开源？**
你可能需要自己运行或审计的部分（中继、Pi 扩展和协议）都是开源的。App 则以签名后的二进制形式发布。

**"Wilco" 是什么意思？**
这是航空无线电用语 "will comply" 的缩写，意思是"收到，照办"。
