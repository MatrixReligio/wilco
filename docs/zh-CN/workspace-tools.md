# 在手机上使用 Mac 上的文件夹

除了会话本身，Wilco 还能让你查看 Pi 工作的文件夹、了解会话的花费、在 Mac 上运行命令、把会话导出成网页分享、为新会话创建独立的 git worktree，以及用口述输入消息。每项功能都需要 Wilco Host 支持；旧版 Host 不会显示对应的选项。

## 文件

在会话页点 **⋯ → 文件**，打开会话在 Mac 上的文件夹。可以进入子文件夹；文件会显示文字（包括 Markdown 和代码），图片则显示图片本身。

- 只读：不会改动 Mac 上的任何内容。
- 只能打开会话文件夹之内的内容。指向文件夹外的链接不会被跟随，`.git` 也不显示。
- 文本文件最多显示前 2 MB。

## 用量

首页顶部的图表按钮显示这台 Mac 最近 7、30 或 90 天的 token 用量和费用，按天列出，并按模型和文件夹汇总。数据由 Mac 根据 Pi 的会话文件计算，也包括在 Mac 终端中启动的会话，因此与 Pi 自己记录的一致。

## 在 Mac 上运行命令

消息以 `!` 开头时，后面的内容会作为 Shell 命令在会话文件夹中运行，和 Pi 在终端里的 `!` 一样。输出会实时显示在会话中，点 **停止** 可结束命令。

- `!` 会把命令和输出留在会话里，Pi 下次会读到；`!!` 运行后不告诉 Pi。
- 哪些设备可以这样做由你的 Mac 决定。在 Wilco Host 中打开 **设备**，为该设备勾选 **允许运行 Shell 命令**。所有设备默认都不允许；没有权限的设备会看到原因。
- 命令以你的 Mac 账户身份、按你的权限运行，请只允许你信任的设备。

## 导出会话

点 **⋯ → 详情 → 导出为 HTML**，Mac 上的 Pi 会为整个会话生成一个网页。完成后点网页的文件名，即可像其他文件一样保存或发送。网页在 Mac 上生成，只把生成好的网页发到手机；之后 Mac 上不会保留它。

## 在独立的 git worktree 中新建会话

如果文件夹是 git 仓库（文件夹本身有 `.git`），新建会话的菜单会在 **在新的 git worktree 中** 下列出它。Pi 会在自己的分支和文件夹中工作，多个会话修改同一个项目时互不干扰。

- worktree 建在仓库内的 `.wilco/worktrees/<id>`，分支为 `wilco/<id>`，基于当前检出的内容。`.wilco/` 会加入仓库的本地排除文件，因此不会显示为改动。
- 首页和会话详情会显示分支名。
- Wilco 不会删除 worktree 或分支：完成后请用 git 合并或删除（`git worktree remove`、`git branch -d`）。
- 还没有任何提交的仓库无法创建 worktree；Wilco 会提示 git 无法创建。

## 口述

点输入框旁的麦克风并说话。识别出的文字会实时出现在草稿中你已输入的内容之后，并随着识别变得确定而稳定下来。再点一次麦克风即可停止；开始打字也会停止口述。

- 语音在你的 iPhone 或 iPad 上转换成文字，不会发送到任何地方去识别。
- 在你点 **发送** 之前，不会有任何内容发给 Pi，你可以先修改文字。
- 第一次使用时，iOS 会请求麦克风和语音识别权限，并可能下载你的语言的语音模型。
