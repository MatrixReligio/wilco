# 在会话中工作

会话页不只是对话记录和输入框。顶部的 **⋯** 菜单和标题下方的信息栏提供了其余功能。

## 分支：从任意一条消息重新开始

打开 **⋯ → 分支**，可以看到你在会话中发送过的所有消息，以树状排列。凡是你曾回到某处换个方向尝试的地方，会话都会分叉；通往 Pi 当前位置的路线会被标出。

点按一条消息，即可**从它之前开始一个新会话**。这条消息会成为草稿，你可以修改后重新发送。原来的会话保持不变，即使 Pi 仍在其中工作也不受影响：新会话在 Mac 上由一个独立的 Pi 运行。

**复制会话**（位于“分支”页顶部）会把整个会话复制成一个新会话。

Mac 上的扩展可以阻止分叉；这时 Wilco 会告诉你。

## 斜杠命令

在消息开头输入 `/`，即可看到 Pi 在此会话中提供的命令：提示模板、技能和扩展命令。继续输入可缩小范围，点按一个命令即可把它放在消息开头。

## 图片

点按输入框旁的 **+**，最多可添加四张图片：来自照片图库、相机，或你复制的内容。图片会随你发送的下一条消息一起发出，引导消息和后续消息也一样。

- 只有当会话所用的模型能读取图片时，才会提供添加图片的选项。换用这样的模型即可添加。
- 每张图片在离开手机前都会被转正并缩小（长边不超过 2048 像素，大小不超过 1.5 MB），因此大照片也能很快发出。

## 改动

Pi 编辑或写入文件后，标题下方的信息栏会显示改动了多少个文件，以及新增和删除的行数（例如 **3 个文件 +42 −7**）。点按它（或 **⋯ → 改动**）可查看列表。每个文件会按顺序以差异形式列出它的各次编辑。

列表来自会话自身的记录：在 Pi 之外或会话开始之前所做的改动不在其中。

## 详情、重命名和压缩

**⋯ → 详情** 显示会话所在的文件夹和模型、消息和工具调用的数量、Token 用量（输入、输出、缓存）、花费，以及模型上下文的占用比例。

- **重命名**：为会话取一个你自己的名字；它会作为标题显示在这里和你的 Mac 上。
- **压缩**：让 Pi 总结目前的会话内容，从而释放模型的上下文空间。结果会显示在对话记录中。Pi 工作时无法压缩。

对于在 Mac 终端中打开的会话，终端无法从外部执行的操作会显示为不可用。
