# 在手机上使用终端会话

像平时一样在 Mac 的“终端”里启动 Pi，然后在 iPhone 或 iPad 上接着使用同一个会话：实时跟随运行、回答它的询问、躺在沙发上发送下一条提示。这一切通过一个小小的 Pi 扩展 [wilco-bridge](../../Bridge/README.zh-CN.md#wilco-bridge) 实现。

## 设置

1. 在 Wilco Host 的设置中打开 **Pi**，点按**终端会话**下的**安装**。（也可以运行 `pi install npm:@matrixreligio/wilco`，它会同时安装 wilco-guard。两种方式都装了也没关系：每个扩展仍然只运行一份。）
2. 确认你工作的文件夹已在 Wilco Host 中共享。
3. 在该文件夹中通过终端启动 Pi。已经打开的会话，下次启动时会加载这个扩展。

## 在手机上

这个会话会出现在首页，并标注**在 Mac 终端中**，打开方式和其他会话一样。你发送的所有内容都交给终端里的 Pi，终端里也会显示出来。

在手机上可以发送提示、在运行中插话引导或排队追加消息、停止运行、切换模型和思考级别、重命名或压缩会话，以及回答 wilco-guard 的询问。终端无法从外部完成的操作（例如清空排队的消息），在会话于终端中打开期间显示为不可用。其他扩展在终端里提出的问题只能在终端里回答，会话页面上会显示有问题在等待。

## 在 Mac 和手机之间切换

同一时间只有一个 Pi 运行某个会话。

- **在终端里打开一个 Wilco Host 正在运行的会话：**如果那边的 Pi 空闲，终端立即接管。如果正在运行，终端会等待并显示提示；Pi 完全停下后，它会重新加载会话（包括这次运行做的所有事情），然后你就可以继续输入。如果手机上正打开着这个会话，之后手机会自动跟随终端。
- **在第二个终端里打开同一个会话：**它会跟随第一个终端并显示提示，等第一个关闭后接管。
- **关闭终端：**会话仍然保留在手机上。下次打开时，Wilco Host 会用自己的 Pi 接着运行。

## 隐私与安全

wilco-bridge 只通过一个仅你的用户能打开的套接字，与同一台 Mac 上的 Wilco Host 通信，从不连接其他地方；你的设备也只能看到已共享文件夹里的会话。Wilco Host 未运行时，终端照常可用。

只有在那个 Pi 中加载了 wilco-guard 时，它才会在执行有风险的命令前询问：Wilco Host 的**安装**只添加 wilco-bridge，如果希望终端里的命令也受检查，请安装 npm 包。参见[批准与通知](notifications-and-approvals.md)。
