# Wilco 使用手册

用 Wilco，你可以在 iPhone 或 iPad 上使用 Mac 上的 [Pi 编程智能体](https://github.com/earendil-works/pi)：开始会话、实时跟进、回答 Pi 的问题、批准有风险的命令、查看改动。在家或在外面都可以。Pi 仍在你的 Mac 上运行，用的是你自己的设置、模型和扩展。代码和密钥不会离开 Mac。

Wilco 分为两部分：

- **Wilco Host**：装在 Mac 上，免费。它替你的设备运行 Pi，并保持设备与 Mac 的连接。
- **Wilco**：iPhone 和 iPad 应用，在 App Store 上提供。

## 1. 准备工作

- 一台 macOS 26（Tahoe）或更新版本的 Mac。
- 这台 Mac 上已安装 [Pi](https://github.com/earendil-works/pi)，在“终端”里能正常运行（输入 `pi` 即可启动），并且至少配置好了一个模型。
- 一台 iOS 或 iPadOS 26 或更新版本的 iPhone 或 iPad。
- 在外面也要连到 Mac 的话，Mac 需要开机、不休眠、联网。除此之外什么都不用：不用端口转发，不用 VPN，也不用注册账号。

想先看看？在 iPhone 或 iPad 上打开 Wilco，轻点 **试用演示**。演示用的 Mac 运行在应用内部，你的任何操作都不会离开设备。

## 2. 在 Mac 上安装 Wilco Host

**直接下载。** 从[最新版本](https://github.com/MatrixReligio/wilco-releases/releases/latest)下载 `Wilco-Host-<版本号>.dmg`，打开后把 **Wilco Host** 拖到“应用程序”文件夹。Wilco Host 经过签名，并通过了 Apple 公证。

**用 Homebrew 安装。**

```sh
brew tap matrixreligio/tap
brew trust matrixreligio/tap   # Homebrew 7 及以上版本需要
brew install --cask wilco-host
```

然后从“应用程序”中打开 Wilco Host。

## 3. 设置 Wilco Host

第一次打开时，Wilco Host 会带你走完五步。任何一步都可以返回或跳过，剩下的之后在它的窗口里完成。

1. **欢迎。**
2. **在后台运行。** 点按 **启动 Wilco Host**。之后只要你登录了 Mac，一个小小的后台 Host 就会一直运行，即使关掉窗口也一样，这样 Mac 开着时你的设备就能连到 Pi。如果 macOS 提示需要你的许可，点按 **打开“登录项”**，在“系统设置”中允许 **Wilco Host**。
3. **Pi。** Wilco Host 会在 Mac 上查找 Pi，并显示找到的版本。如果显示 **未找到 Pi**，请安装 Pi，确认在“终端”里能用 `pi` 启动，然后点按 **重新检查**。（也可以先完成设置，Wilco Host 之后会自己找到 Pi。）
4. **共享文件夹。** 点按 **共享文件夹…**，选择一个项目。Pi 只能在你共享的文件夹里工作、读取和修改文件。先共享一个，以后可以再加。
5. **配对 iPhone 或 iPad。** 点按 **配对设备…**，然后按下一节操作。

之后 Wilco Host 会常驻在菜单栏。点按它的图标，可以看到正在运行的会话、你的设备，以及 **配对设备…** 和 **打开 Wilco Host**。

## 4. 配对 iPhone 或 iPad

1. 在 Mac 上：点按 **配对设备…**（在菜单栏里，或 Wilco Host 窗口顶部的二维码按钮）。屏幕上会出现一个二维码。每个配对码只能用一次，10 分钟内有效；要换一个，点按 **新配对码**。
2. 在 iPhone 或 iPad 上：从 App Store 安装 **Wilco: Pi Remote**，打开后轻点 **配对 Mac**。允许使用相机，扫描二维码。（没有相机？在 Mac 上点按 **拷贝链接**，把链接发到设备上，粘贴到 **或粘贴配对链接** 下面。）
3. 如果 iOS 询问是否允许 Wilco 查找本地网络上的设备，请允许。在家时，Wilco 靠它直接连接你的 Mac。
4. 设备上会显示一个六位数代码，Mac 会询问是否允许这台设备配对。**只有两边显示的代码相同时才批准。**

完成。之后能走局域网时，设备会直接连接 Mac；在外面时则通过 Wilco 中继连接。切换是自动的，主屏幕顶部的指示会显示 **局域网** 或 **通过中继**。

## 5. 会话

### 主屏幕

主屏幕像机场的航班显示屏一样列出你的会话：**等你处理** 的排在最前，然后是 **运行中**，再是已完成、**待查看** 的，最后是 **最近**。每张卡片显示文件夹、Pi 当前的步骤，以及模型上下文用了多少。配对了多台 Mac 时，所有 Mac 的会话会列在一起。

### 开始会话

轻点 **新会话**，选择一个从 Mac 共享的文件夹。输入你想让 Pi 做的事，轻点 **发送**。如果文件夹是一个 git 仓库，还会出现在 **在新的 git worktree 中** 下面：选它，Pi 就在自己的分支和单独的文件夹里工作（见[工作区工具](workspace-tools.md)）。

之前开始的会话，无论是在手机上还是在 Mac 上开始的，也都在主屏幕上。打开一个就能继续；需要时 Wilco Host 会重新为它启动 Pi。

### Pi 工作时

会话会实时显示 Pi 正在写的回答、它的思考过程（轻点展开），以及每一次工具调用：读了哪些文件、改动以 diff 显示、命令和它的输出。轻点某一步可以看详情。

Pi 工作时，输入框提供三种发送方式：

- **引导**：Pi 在下一步读到你的消息，不会停下来。
- **后续**：消息先排队，等 Pi 完成后开始下一轮。
- **停止**：结束当前这次运行。会话还在，你可以接着发消息。

排队中的消息显示在输入框上方；**清空队列** 可以撤掉它们。

### 模型和思考强度

轻点会话标题下方信息栏里的模型名称，可以换模型，或调整 Pi 思考的程度（从 **已关闭**、**最低** 到 **极高**，取决于模型支持哪些）。可选的模型就是 Mac 上 Pi 已配置的那些，使用你自己的密钥。

### 少打字

- **斜杠命令**：在消息开头输入 `/`，可以看到 Pi 的提示词模板、技能和扩展提供的命令。
- **照片**：轻点 **+**，最多附加四张图片（模型需要能读图）。
- **听写**：轻点麦克风说话。语音在你的设备上识别。
- **Shell 命令**：消息以 `!` 开头，就会在 Mac 上运行这条命令。默认关闭，需要在 Mac 上为这台设备打开（见[工作区工具](workspace-tools.md)）。

## 6. 批准

Wilco Host 启动的每个会话都带着 **wilco-guard**。Pi 在执行有风险的命令或在文件夹之外写文件之前，会停下来询问。问题会出现在会话里（也会作为通知发出）；Pi 会一直等着，没有时间限制，直到你轻点 **批准** 或 **拒绝**。

要询问哪些事，可以在应用的 **设置 → 你的 Mac → 需要批准** 中选择，也可以在 Mac 上 Wilco Host 的 **Pi** 部分设置：

- **危险命令**（默认打开）：如 `rm -r`、`sudo`、`git push --force` 这类命令。
- **所有命令**：Pi 运行的任何 Shell 命令。
- **文件夹之外的修改**（默认打开）：在会话文件夹之外写入或编辑文件。

这些规则保存在 Mac 上，并立即作用于正在运行的会话。Pi 的其他询问（扩展发出的选择、确认、文本输入）也会以同样的方式出现在会话里。

## 7. 通知、实时活动、小组件和 Siri

在 **设置 → 通知** 中打开通知，并选择想收到哪些：**询问与批准**、**运行完成** 和 **运行出错**。通知端到端加密，只有你的设备能读。

- **在锁定屏幕上处理**：关于一条短命令的询问，通知上会直接显示 **批准** 和 **拒绝**，需要先通过面容 ID、触控 ID 或密码。较长的命令会在应用中打开，确保你批准的正是你看到的内容。
- **实时活动**：从应用发起的运行会出现在锁定屏幕和灵动岛上，显示状态、步数和用时。可以在 **设置 → 通知** 中关闭。
- **小组件**：把 **Pi 会话** 小组件加到主屏幕，就能看到哪些等你处理、哪些在运行。
- **Siri 和快捷指令**：说“用 Wilco 问 Pi”可以在某个文件夹开始新会话；说“Pi 在 Wilco 里做什么”可以听到概况。两者都需要先解锁设备。

更多内容见[批准与通知](notifications-and-approvals.md)。

## 8. 会话里的更多功能

会话顶部的 **⋯** 菜单和标题下方的信息栏里还有：

- **改动**：Pi 在这个会话里编辑或写入的所有文件，以及增删的行数；每个文件都能以 diff 打开。
- **分支**：你发过的所有消息，以树状显示。轻点其中一条，就从它之前开始一个新会话；也可以 **复制会话**。
- **文件**：只读浏览会话在 Mac 上的文件夹。
- **详情**：文件夹、模型、消息数、token、费用和上下文。在这里还能 **重命名**、**压缩**（总结目前的会话，腾出上下文空间）和 **导出为 HTML**。

主屏幕上的图表按钮打开 **用量**：最近 7、30 或 90 天的 token 和费用，可按模型和文件夹查看。

详见：[在会话中工作](session-tools.md) · [工作区工具](workspace-tools.md)。

## 9. 终端会话

照常在“终端”里启动 Pi，然后在手机上接着同一个会话。只需在 Wilco Host 的 **Pi** 部分，点按 **终端会话** 下的 **安装** 一次。之后在共享文件夹里用“终端”运行的会话，会出现在主屏幕上，并标注 **在 Mac 终端中**。详见[终端会话](terminal-sessions.md)。

## 10. 日常使用 Wilco Host

从菜单栏点按 **打开 Wilco Host** 打开窗口。侧边栏各部分：

| 部分 | 用途 |
| --- | --- |
| **概览** | Wilco Host 是否就绪；运行中的会话、在线设备、共享文件夹、连接数；最近的会话。 |
| **会话** | 这台 Mac 上的所有会话；**停止会话** 可以结束正在运行的会话（之后还能继续）。 |
| **设备** | 已配对的 iPhone 和 iPad，以及最后在线时间。可以为每台设备打开 **允许运行 Shell 命令**；**移除设备** 即取消配对。 |
| **文件夹** | Pi 可以工作的文件夹。**共享文件夹…**、**停止共享…**。 |
| **连接** | **允许设备连接**（关闭后所有设备都会断开，直到你重新打开）、**随时随地连接这台 Mac**（中继），以及可选的 **中继地址**（填你自己运行的中继）。 |
| **Pi** | 找到的 Pi 版本、**终端会话**，以及 **需要批准**（与应用中的规则相同）。 |
| **日志** | Wilco Host 打开期间的连接、配对和会话记录。 |
| **设置** | **在后台运行**，以及 **更新**：自动检查、**稳定版** 或 **测试版** 通道、**登录时在菜单栏中打开**、**检查更新…**。 |

从菜单栏退出只会关闭窗口和菜单，后台 Host 仍会为你的设备继续运行（**退出（Host 继续运行）**）。要停止它，请在设置中关闭 **在后台运行**。

## 11. 多台 Mac、多台设备

- **再加一台 Mac**：在那台 Mac 上安装 Wilco Host，用同样的方法配对（应用中 **设置 → 配对 Mac…**）。主屏幕会列出所有 Mac 的会话。
- **再加一台 iPhone 或 iPad**：在 Mac 上生成新的配对码来配对。每台设备都有自己的密钥。
- **移除**：在应用中，**设置 → 你的 Mac → 移除这台 Mac**。在 Mac 上，**设备 → 移除设备** 会立即断开那台设备。

## 12. 更新

- **Wilco Host** 会自动更新：打开时检查，在后台下载，在没有会话运行时安装。**设置 → 更新** 里有 **检查更新…**、自动检查，以及 **稳定版**/**测试版** 通道。用 Homebrew 安装的也可以运行 `brew upgrade --cask wilco-host`。
- **Wilco** 通过 App Store 更新。当应用和 Wilco Host 版本相差太多时，应用会告诉你该更新哪一个。

## 13. 隐私与安全

- 没有账号，没有跟踪，没有统计分析。应用不收集任何数据。
- 你的代码、密钥和 Pi 会话都留在 Mac 上。应用会缓存你打开过的内容，方便离线查看。
- 设备和 Mac 之间的每一条连接都是端到端加密的（Noise 协议）。中继只转发它读不懂的加密数据，不保存任何东西；你也可以[自己运行一个中继](self-hosting-relay.md)。
- Pi 只能在你共享的文件夹里工作，wilco-guard 会在有风险的命令之前先问你。

详见：[安全模型](security-model.md) · [隐私政策](https://matrixreligio.com/en/products/wilco/privacy/)。

## 14. 常见问题排查

| 你看到的 | 怎么办 |
| --- | --- |
| **无法连接到你的 Mac** | 确认 Mac 开着、没有休眠、已联网，并且 Wilco Host 正在运行（菜单栏有它的图标）。Wilco Host 中 **连接 → 允许设备连接** 必须打开。 |
| 在家能连上，在外面连不上 | **连接 → 随时随地连接这台 Mac** 必须打开。如果设置了自己的 **中继地址**，请检查那个中继。 |
| **配对未完成** 或 **代码已过期** | 在 Mac 上生成 **新配对码** 再扫一次。只有两边代码相同时才在 Mac 上批准。 |
| **未找到 Pi** | 安装 Pi，确保在“终端”里能用 `pi` 启动。Wilco Host 会自己找到它，之后 **Pi** 部分会显示版本。 |
| **Pi 无法在你的 Mac 上启动** | 在那个文件夹里用“终端”运行 `pi`，它会显示问题所在（通常是模型或密钥）。 |
| **另一个应用正在使用 Wilco Host 的网络端口** | 退出那个应用，Wilco Host 会自己启动。 |
| **Wilco Host 已在“终端”中运行** | 在“终端”中停止 `wilcod run`，后台 Host 就会启动。 |
| **在“登录项”中允许 Wilco Host** | 系统设置 → 通用 → 登录项与扩展：允许 Wilco Host。 |
| 收不到通知 | iOS 设置 → 通知 → Wilco 需要允许；并在 Wilco 的 **设置 → 通知** 中打开你想要的类型。 |
| **Mac 上的 Wilco Host 比本 App 新** | 从 App Store 更新 Wilco。 |
| 其他问题 | Wilco Host 的 **日志** 会显示发生了什么。可以在[支持页面](https://matrixreligio.com/en/products/wilco/)反馈。 |

## 15. 卸载

- **iPhone 或 iPad**：删除应用即可。再在 Mac 上的 **设备** 中移除这台设备。
- **Mac，用 Homebrew 安装的**：`brew uninstall --cask wilco-host`（加上 `--zap` 会同时删除它的设置和配对信息）。
- **Mac，手动安装的**：在 Wilco Host 的设置中关闭 **在后台运行**，退出它，然后把“应用程序”里的 **Wilco Host** 移到废纸篓。它的数据在 `~/Library/Application Support/Wilco`。

两种方式都不会动你的 Pi、它的设置和会话。
