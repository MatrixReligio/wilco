# 中继（协议版本 1）

设备和 Host 不在同一网络时，通过中继连接。中继转发[安全通道](secure-channel.zh-CN.md)的消息，但无法读取内容：它只能看到频道 ID、连接 ID 和消息大小。Host 可以使用官方托管的中继，也可以[自建](../docs/zh-CN/self-hosting-relay.md)。

JSON 和 URL 中的二进制值都使用不带填充的 base64url。下文用 `a ‖ b` 表示字节串拼接，`0x00` 表示一个零字节。

## 频道与 Host 密钥

每台 Host 有一把用于中继的 Ed25519 密钥，与安全通道使用的 X25519 密钥分开。它的**频道 ID** 为

```text
channel = base64url(SHA-256(Ed25519 公钥)) 的前 22 个字符
```

因此频道属于持有这把密钥的人，不需要账号。配对邀请中带有频道（`r`），如果使用的不是默认中继，还带有中继地址（`u`）。

## Host 连接

Host 打开到 `wss://<relay>/v1/host/<channel>` 的 WebSocket 并保持连接。

1. 中继 → Host，文本：`{"type":"challenge","nonce":"<32 字节>"}`。
2. Host → 中继，文本：`{"type":"auth","key":"<Ed25519 公钥>","sig":"<签名>"}`，签名的内容为
   `"wilco-relay/1" ‖ 0x00 ‖ "host" ‖ 0x00 ‖ channel ‖ 0x00 ‖ nonce`。
3. 中继检查该公钥对应的频道 ID 与 URL 中的一致、签名有效，然后回复 `{"type":"ready"}`；否则以代码 4401 关闭连接。每个 nonce 只能使用一次。

Host 须在 10 秒内完成认证；在 `ready` 之前发送 `auth` 以外的任何消息都会导致连接关闭（4401）。每个频道最多同时保留 4 个尚未认证的连接，再多的以 `429` 拒绝。只有已认证的 Host 连接才算数：在此之前，设备会收到 `503`。

同一频道的新 Host 连接通过认证后，会取代旧连接：中继关闭旧连接，以及经由它的所有设备连接。

Host 可以随时发送文本消息 `ping`，中继回复 `pong`。

### 多路复用的设备连接

设备连接以二进制消息的形式经由 Host 连接到达：

```text
frame = 类型（1 字节）‖ 连接 ID（4 字节，大端）‖ 负载
```

| 类型 | 方向 | 负载 |
|---|---|---|
| `1` open | 中继 → Host | 设备令牌的 ID（16 字节） |
| `2` data | 双向 | 一条安全通道消息 |
| `3` close | 双向 | 空 |

连接 ID 由中继分配，在同一个 Host 连接存续期间不会重复使用。发往未知或已关闭连接的数据会被忽略。Host 发送 `close` 后，中继关闭该设备的 WebSocket；设备挂断时，中继发送 `close`。

Host 移除设备时还会发送 `{"type":"revoke","id":"<令牌 ID>"}`：中继记住这个 ID，此后拒绝它，并关闭使用它的连接。

## 设备连接

设备打开到下面地址的 WebSocket：

```text
wss://<relay>/v1/connect/<channel>?token=<中继令牌>
```

设备只能发送二进制消息，文本消息会导致连接关闭（代码 1003）。每条二进制 WebSocket 消息就是一条安全通道消息（连接前导、握手消息，然后是传输消息），与 TCP 上的完全相同，只是没有长度前缀。升级连接之前，中继可能返回：

| 状态码 | 情形 |
|---|---|
| `401` | 缺少令牌、令牌格式错误，或签名不是该 Host 的 |
| `403` | 令牌已被撤销或已过期 |
| `503` | Host 未连接 |
| `429` | 该频道的设备连接过多 |

## 中继令牌

令牌由 Host 签发；中继用 Host 的公钥校验，从不保存令牌。

```text
body  = 版本（1 字节，1）‖ 类型（1 字节）‖ ID（16 字节）‖ 过期时间（8 字节，大端 Unix 秒；0 表示不过期）
token = body ‖ Ed25519 签名("wilco-relay-token/1" ‖ 0x00 ‖ channel ‖ 0x00 ‖ body)
```

| 类型 | 用途 |
|---|---|
| `1` 设备 | 通过 `relay` 控制消息发给已配对的设备。每台设备一个随机 ID，不过期；撤销设备即撤销该 ID。 |
| `2` 配对 | 放在配对邀请中（`t`），使设备能通过中继完成配对。随邀请一同过期。 |

## 限制

托管中继采用以下限制，自建中继可以修改。

- 单条 WebSocket 消息最大 1 MiB；超出时关闭发送方的连接（代码 1009）。
- 每个频道最多 32 个设备连接。
- 每个频道每分钟最多转发 64 MiB；超出时关闭超额的设备连接（代码 4429）。
- 设备连接 10 分钟没有流量即被关闭。存活的连接不会空闲：Host 安静时，设备每 15 秒确认一次。

## 关闭代码

| 代码 | 含义 |
|---|---|
| `1000` | 正常关闭，或 Host 用 `close` 帧关闭 |
| `1003` | 设备发送了文本消息 |
| `1009` | 消息超过大小限制 |
| `1012` | Host 断开或重新连接（设备连接） |
| `4401` | Host 认证失败或未完成认证 |
| `4403` | 设备的令牌已被撤销 |
| `4408` | 设备连接空闲过久 |
| `4409` | 更新的 Host 连接取代了这一个 |
| `4429` | 超出频道的速率限制 |
