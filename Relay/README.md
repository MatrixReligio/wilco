# Wilco Relay

**English** · 简体中文说明见 [docs/zh-CN/self-hosting-relay.md](../docs/zh-CN/self-hosting-relay.md)

A Cloudflare Worker with one Durable Object per host channel. It forwards encrypted Wilco frames between your Mac and your devices, and sends end-to-end encrypted push notifications through APNs. It cannot read any of the traffic it forwards.

> Status: planned for milestone M2. See [Self-hosting the relay](../docs/en/self-hosting-relay.md).
